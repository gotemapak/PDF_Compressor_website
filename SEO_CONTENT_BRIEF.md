# SEO Content Brief — compressor-pdf.com

Draft for human review. Nothing here has been applied to live `index.html`.

## 1. Target keywords (prioritized)

Priority order: US → Tier-1 English (UK/CA/AU) → Indonesia/Philippines (English-language targeting, no translation) → rest of world.

1. **pdf compressor chrome extension** — primary product-category term, high commercial intent, matches exact product type.
2. **compress pdf without uploading** / **compress pdf offline** — differentiator term; most competing tools are upload-to-server web apps, this extension isn't.
3. **reduce pdf file size free** — high-volume generic intent term, matches "free" + "reduce file size" claims already on page.
4. **free pdf compressor for chrome** — branded-category + "free" modifier, strong for US/UK/CA/AU searches that specify browser.
5. **shrink pdf file size offline** — long-tail variant pairing "shrink" (common colloquial query) with the privacy/offline angle.
6. **batch pdf compression tool** — matches the "batch processing" feature already claimed; useful mid-funnel term.
7. **compress large pdf 150mb** — long-tail, matches the specific 150MB limit fact; captures users hitting size caps on other tools (many online compressors cap at 10-25MB free tier, which is a real pain point this product doesn't have).
8. **pdf compressor without internet** — secondary offline-angle phrase, good fit for Indonesia/Philippines segment where connectivity/data cost is a more prominent search driver.

Note on ID/PH: no localized (Bahasa/Tagalog) content recommended per scope — target with English-language pages/metadata only, since the product UI and page are English.
